WHERE TO PUT IMAGES
===================
Two ways. Use the right one for each image.

A) Drop a file in THIS folder (static/img/) using the EXACT name below.
   No code change needed. Refresh the browser (Ctrl+Shift+R).

   hero.jpg   Home page big banner.   Wide photo of the school, about 1920x1080, under 500 KB
   about.jpg  About page banner.      Wide photo, about 1600x500
   logo.png   Logo in the top menu.   Square PNG, transparent background, about 200x200

B) Upload through the website: log in as admin, then Admin > "Manage photos..."
   Proprietor, headmistress and staff   Portrait photo (4:5), about 800x1000
   Gallery (students, events)           Any landscape photo, about 1200 px wide
   Classmates profile photos            Members upload their own at "My profile"
   Each upload must be PNG, JPG or WEBP and under 5 MB.
